# Новостной Telegram-канал: автопостинг

Каждые 10 минут Планировщик Windows запускает `main.py tick`. Скрипт собирает RSS
(Gazeta.uz, Kun.uz, Spot.uz, Daryo, DW, BBC и др.), Gemini выбирает самую важную
новость и переписывает её, Pillow делает картинку со стоковым фото Pixabay, бот
публикует пост в канал со ссылкой на источник.

## Подключение (один раз)

1. В Telegram создать публичный канал и придумать ему @юзернейм.
2. У @BotFather: `/newbot` → получить токен.
3. Добавить бота в администраторы канала с правом «Публикация сообщений».
4. Вписать в `.env`:
   ```
   BOT_TOKEN=123456:ABC...
   CHANNEL_ID=@юзернейм_канала
   ```
5. Проверить: `python main.py check`, затем `python main.py now` (первый пост).

Дальше всё идёт само: задача `UzNewsBot` в Планировщике уже создана.

## Что выходит за день

| Время (Ташкент) | Что |
|---|---|
| 08:00 | Курсы ЦБ + погода в Ташкенте (картинка) |
| 07:00–23:00 | Новость каждые ~50 минут, 65% Узбекистан / 35% мир |
| 21:00 | Дайджест «Главное за день» со ссылками на посты |

## Команды

- `python main.py preview` — пост в папку `preview/` без публикации
- `python main.py now` — опубликовать новость сейчас
- `python main.py rates` — превью поста с курсами
- `python main.py check` — проверка токена и прав

Настройки (название канала, частота, источники, доля мировых новостей) — в `config.yaml`.
Лог — `logs/bot.log`. Остановить автопостинг: `schtasks /Change /TN UzNewsBot /Disable`.

Компьютер должен быть включён: пока нет VPS, посты выходят только когда он работает.
